About Jansetu

What is Jansetu?

Jansetu (जनसेतु) means "Bridge for the People." It is an eligibility-based government scheme recommendation system that connects Indian citizens to the welfare benefits they deserve.

Many eligible citizens miss out on government schemes simply because they are unaware of them. Jansetu solves this by asking a few simple questions about your profile and instantly matching you with schemes you qualify for.

Built as a B.Tech Computer Science project, demonstrating end-to-end full-stack development with Java backend, MySQL database, and a pure HTML/CSS/JS frontend.

🛠️ Technologies Used

HTML5 CSS3 JavaScript (ES6) Core Java JDBC MySQL Java HttpServer
✓MySQL-backed registration & login
✓HttpOnly session cookies — no token exposure
✓Profile-based eligibility matching
✓8+ real Indian government schemes
✓Responsive — works on all devices
